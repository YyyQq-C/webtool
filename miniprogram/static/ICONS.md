# 需要的图标文件

## 1. logo.png
- 尺寸: 200x200 px
- 格式: PNG (透明背景)
- 用途: 应用 Logo，显示在首页和关于页面
- 建议: 使用蓝胖子的口袋原有 Logo 或简化版本

## 2. TabBar 图标
需要 4 个文件，每个 40x40 px：

### tab-tools.png
- 未选中状态的"工具"图标
- 建议使用工具箱/网格图标
- 颜色: 灰色 (#6B7280)

### tab-tools-active.png
- 选中状态的"工具"图标
- 建议使用工具箱/网格图标
- 颜色: 绿色 (#10B981)

### tab-about.png
- 未选中状态的"关于"图标
- 建议使用信息圆圈图标
- 颜色: 灰色 (#6B7280)

### tab-about-active.png
- 选中状态的"关于"图标
- 建议使用信息圆圈图标
- 颜色: 绿色 (#10B981)

## 临时方案

在开发阶段，可以：
1. 使用 emoji 作为占位
2. 使用纯色方块作为临时图标
3. 从 Web 版的 public 目录复制图标

## 图标资源建议

- [iconfont.cn](https://www.iconfont.cn/) - 阿里巴巴矢量图标库
- [undraw.co](https://undraw.co/illustrations) - 开源 SVG 图标
- 使用 Figma 或 Sketch 自行设计
